# 数据字典

**版本**: v1.0

## 📋 说明

本文档汇总 ChordSked 系统所有数据表的字段定义，供开发参考。

---

## 📊 数据表清单

| 表名 | 说明 | 来源文档 |
|-----|------|---------|
| sys_user | 用户表 | 01-认证模块需求 |
| sys_login_log | 登录日志表 | 01-认证模块需求 |
| sys_sms_code | 短信验证码表 | 01-认证模块需求 |
| sys_role | 角色表 | 02-授权模块需求 |
| sys_permission | 权限表 | 02-授权模块需求 |
| sys_user_role | 用户 - 角色关联表 | 02-授权模块需求 |
| sys_role_permission | 角色 - 权限关联表 | 02-授权模块需求 |
| sys_organization | 组织表（含校区） | 06-组织架构需求 |
| sys_user_org | 用户 - 组织关联表 | 06-组织架构需求 |
| sys_data_scope | 数据权限配置表 | 06-组织架构需求 |
| sys_operation_log | 操作日志表 | 05-审计日志需求 |

**设计说明**: 校区与组织统一为 `sys_organization` 表，通过 `type` 字段区分类型，不再单独建表。

## 📁 表结构详情

### sys_user - 用户表

| 字段 | 类型 | 长度 | 必填 | 默认 | 约束 | 说明 |
|-----|------|------|-----|------|------|------|
| id | BIGINT | - | 是 | - | 主键 | 用户 ID |
| username | VARCHAR | 50 | 后台用户必填 | - | 唯一 | 用户名（仅后台用户） |
| password | VARCHAR | 100 | 是 | - | - | 密码（BCrypt 加密） |
| phone | VARCHAR | 20 | 是 | - | 唯一 | 手机号 |
| name | VARCHAR | 50 | 是 | - | - | 姓名 |
| avatar | VARCHAR | 200 | 否 | - | - | 头像 URL |
| status | TINYINT | 1 | 是 | 1 | - | 状态（0 禁用/1 启用） |
| must_change_password | TINYINT | 1 | 是 | 0 | - | 首次登录需改密 |
| login_fail_count | INT | - | 是 | 0 | - | 登录失败次数 |
| locked_until | DATETIME | - | 否 | NULL | - | 锁定截止时间 |
| created_at | DATETIME | - | 是 | - | - | 创建时间 |
| updated_at | DATETIME | - | 是 | - | - | 更新时间 |

## 🔗 实体关系

```
sys_user ──┬── sys_user_role ── sys_role ──┬── sys_role_permission ── sys_permission
           │                               │
           │                               └── sys_organization (data_scope=CAMPUS 时)
           │
           ├── sys_user_org ── sys_organization
           │
           ├── sys_login_log
           │
           └── sys_operation_log
```

## 📝 枚举值说明

### sys_user.status

| 值 | 说明 |
|-----|------|
| 0 | 禁用 |
| 1 | 启用 |

### sys_role.data_scope

| 值 | 说明 |
|-----|------|
| ALL | 全部数据 |
| CAMPUS | 本校区数据 |
| ASSIGNED | 已分配数据 |
| SELF | 个人数据 |

### sys_permission.type

| 值 | 说明 |
|-----|------|
| 1 | 菜单权限 |
| 2 | 按钮权限 |
| 3 | 数据权限 |

### sys_organization.type

| 值 | 说明 | 层级 | 特有字段 |
|-----|------|------|---------|
| CAMPUS | 校区 | 1（根节点） | address, phone |
| DEPT | 部门 | 2（校区的下级） | - |
| GROUP | 小组 | 3（部门的下级） | - |

### sys_data_scope.scope_type

| 值 | 说明 |
|-----|------|
| ALL | 全部组织 |
| SPECIFIED | 指定组织（多选） |
| CURRENT_AND_SUB | 本组织及下级 |
| CURRENT | 仅本组织 |
| SELF | 个人数据 |
