# 01-认证模块需求

**优先级**: P0  
**涉及端**: 后端、教务端、小程序端

---

## 1. 功能概述

实现多端用户认证，支持后台用户账号密码登录和小程序手机号验证码登录。

---

## 2. 用户故事

### 2.1 后台用户登录

**作为** 教务管理员/教师  
**我希望** 使用账号密码登录系统  
**以便** 管理系统和业务数据

**验收标准**:
- 输入账号和密码后可登录
- 密码错误时提示明确错误信息
- 登录成功后跳转到首页
- 登录状态持久化

### 2.2 小程序用户登录

**作为** 学员/家长  
**我希望** 使用手机号 + 短信验证码登录小程序  
**以便** 预约课程和查看学习记录

**验收标准**:
- 输入手机号可获取短信验证码
- 验证码有效期 5 分钟
- 验证码错误时提示明确错误信息
- 登录成功后可正常使用小程序

### 2.3 登录失败限制

**作为** 系统管理员  
**我希望** 限制连续登录失败次数  
**以便** 防止暴力破解攻击

**验收标准**:
- 连续 5 次登录失败后锁定账号 30 分钟
- 锁定时提示明确锁定信息
- 锁定时间结束后自动解锁

### 2.4 首次登录修改密码

**作为** 新入职员工  
**我希望** 首次登录时强制修改密码  
**以便** 确保账号安全

**验收标准**:
- 新账号首次登录时跳转改密页面
- 不改密无法进行其他操作
- 新密码符合复杂度要求（8 位以上，含大小写字母 + 数字）

---

## 3. 功能详情

### 3.1 后台用户登录

**功能描述**:
- 用户输入用户名和密码
- 系统验证账号密码
- 验证通过后生成登录凭证
- 记录登录日志

**输入**:
- 用户名
- 密码

**输出**:
- 登录成功：返回用户信息、登录凭证
- 登录失败：返回错误原因

**业务规则**:
- 密码验证失败时不提示具体是账号还是密码错误
- 账号被禁用时明确提示
- 首次登录强制修改密码

### 3.2 小程序用户登录

**功能描述**:
- 用户输入手机号
- 获取短信验证码
- 输入验证码后登录
- 手机号不存在时自动创建学员账号

**输入**:
- 手机号
- 短信验证码

**输出**:
- 登录成功：返回用户信息、登录凭证
- 登录失败：返回错误原因

**业务规则**:
- 验证码有效期 5 分钟
- 手机号不存在时自动创建学员账号
- 新账号默认角色为"学员"

### 3.3 短信验证码发送

**功能描述**:
- 用户输入手机号请求验证码
- 系统验证手机号格式
- 发送短信验证码

**输入**:
- 手机号
- 验证码用途（登录/注册/重置密码）

**输出**:
- 发送成功：提示验证码已发送
- 发送失败：返回错误原因

**业务规则**:
- 60 秒内只能发送 1 次
- 验证码 6 位数字
- 验证码 5 分钟有效

### 3.4 登录凭证刷新

**功能描述**:
- 登录凭证即将过期时自动刷新
- 用户无感知继续使用系统

**业务规则**:
- 凭证过期前自动刷新
- 刷新后旧凭证失效
- 凭证失效后需重新登录

### 3.5 修改密码

**功能描述**:
- 用户可修改自己的登录密码
- 首次登录强制修改密码

**输入**:
- 旧密码
- 新密码

**输出**:
- 修改成功：提示成功
- 修改失败：返回错误原因

**业务规则**:
- 需验证旧密码
- 新密码需符合复杂度要求
- 修改成功后需重新登录

### 3.6 登出

**功能描述**:
- 用户主动退出登录
- 清除登录状态

**业务规则**:
- 登出后凭证立即失效
- 记录登出日志

## 4. 数据要求

### 4.1 用户表 (sys_user)

| 字段 | 类型 | 长度 | 必填 | 约束 | 说明 |
|-----|------|------|-----|------|------|
| id | BIGINT | - | 是 | 主键 | 用户 ID |
| username | VARCHAR | 50 | 后台用户必填 | 唯一 | 用户名（仅后台用户） |
| password | VARCHAR | 100 | 是 | - | 密码（BCrypt 加密） |
| phone | VARCHAR | 20 | 是 | 唯一 | 手机号 |
| name | VARCHAR | 50 | 是 | - | 姓名 |
| avatar | VARCHAR | 200 | 否 | - | 头像 URL |
| status | TINYINT | 1 | 是 | 默认 1 | 状态（0 禁用/1 启用） |
| must_change_password | TINYINT | 1 | 是 | 默认 0 | 首次登录需改密 |
| login_fail_count | INT | - | 是 | 默认 0 | 登录失败次数 |
| locked_until | DATETIME | - | 否 | - | 锁定截止时间 |
| created_at | DATETIME | - | 是 | - | 创建时间 |
| updated_at | DATETIME | - | 是 | - | 更新时间 |

### 4.2 登录日志表 (sys_login_log)

| 字段 | 类型 | 长度 | 必填 | 约束 | 说明 |
|-----|------|------|-----|------|------|
| id | BIGINT | - | 是 | 主键 | 日志 ID |
| user_id | BIGINT | - | 是 | 外键 | 用户 ID |
| username | VARCHAR | 50 | 是 | - | 用户名 |
| ip | VARCHAR | 50 | 是 | - | 登录 IP |
| user_agent | VARCHAR | 200 | 否 | - | 用户代理 |
| result | TINYINT | 1 | 是 | - | 结果（0 失败/1 成功） |
| message | VARCHAR | 200 | 否 | - | 失败原因 |
| created_at | DATETIME | - | 是 | - | 登录时间 |

### 4.3 短信验证码表 (sys_sms_code)

| 字段 | 类型 | 长度 | 必填 | 约束 | 说明 |
|-----|------|------|-----|------|------|
| id | BIGINT | - | 是 | 主键 | 记录 ID |
| phone | VARCHAR | 20 | 是 | 索引 | 手机号 |
| code | VARCHAR | 10 | 是 | - | 验证码（6 位数字） |
| scene | VARCHAR | 20 | 是 | - | 用途（login/register/reset） |
| expire_at | DATETIME | - | 是 | - | 过期时间（5 分钟） |
| created_at | DATETIME | - | 是 | - | 创建时间 |

## 5. 异常处理

| 异常场景 | 提示信息 |
|---------|---------|
| 账号或密码错误 | 账号或密码错误 |
| 账号已被禁用 | 账号已被禁用，请联系管理员 |
| 账号已锁定 | 账号已锁定，请 30 分钟后重试 |
| 验证码错误或已过期 | 验证码错误或已过期，请重新获取 |
| 验证码发送过于频繁 | 发送过于频繁，请稍后再试 |
| 新密码不符合要求 | 密码需 8 位以上，包含大小写字母和数字 |
| 旧密码错误 | 旧密码错误 |
| 登录凭证已过期 | 登录已过期，请重新登录 |

---

## 6. 安全要求

1. **密码存储**: 密码必须加密存储，不可明文
2. **登录失败限制**: 5 次失败后锁定 30 分钟
3. **凭证有效期**: 登录凭证需设置合理有效期
4. **HTTPS**: 生产环境必须使用 HTTPS
5. **敏感信息**: 不返回密码等敏感信息
