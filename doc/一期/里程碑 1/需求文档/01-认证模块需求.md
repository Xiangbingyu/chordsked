# 01-认证模块需求

**优先级**: P0  
**涉及端**: 后端、教务端、教师端、小程序端

---

## 1. 功能概述

实现多端用户认证，支持三套独立账号体系的登录认证。

**设计说明**:
- **教务端账号**（ADMIN/OPERATOR）：账号密码登录，使用 `sys_internal_user` 表，有角色概念
- **教师端账号**（TEACHER）：手机号/工号 + 密码登录，使用 `sys_teacher_user` 表，无角色概念
- **学员用户**（STUDENT）：手机号 + 短信验证码登录，使用 `sys_student_user` 表，**无密码字段**
- 三套账号体系完全独立
- 学员账号仅支持后台手动创建，不支持登录时自动创建

## 2. 用户故事

### 2.1 教务端账号登录

**作为** 教务管理员/教务运营  
**我希望** 使用账号密码登录系统  
**以便** 管理系统和业务数据

**验收标准**:
- 输入用户名和密码后可登录
- 密码错误时提示明确错误信息
- 登录成功后跳转到首页
- 登录状态持久化

### 2.2 教师端账号登录

**作为** 教师  
**我希望** 使用手机号/工号 + 密码登录系统  
**以便** 管理教学和学员数据

**验收标准**:
- 输入手机号/工号和密码后可登录
- 密码错误时提示明确错误信息
- 登录成功后跳转到教师端首页
- 登录状态持久化

### 2.3 小程序用户登录

**作为** 学员  
**我希望** 使用手机号 + 短信验证码登录小程序  
**以便** 预约课程和查看学习记录

**验收标准**:
- 输入手机号可获取短信验证码
- 验证码有效期 5 分钟
- 验证码错误时提示明确错误信息
- 登录成功后可正常使用小程序
- 手机号不存在时提示账号不存在（不自动创建）

### 2.4 登录失败限制

**作为** 系统管理员  
**我希望** 限制连续登录失败次数  
**以便** 防止暴力破解攻击

**验收标准**:
- 连续 5 次登录失败后锁定账号 30 分钟
- 锁定时提示明确锁定信息
- 锁定时间结束后自动解锁

### 2.5 首次登录修改密码

**作为** 新入职员工/教师  
**我希望** 首次登录时强制修改密码  
**以便** 确保账号安全

**验收标准**:
- 新账号首次登录时跳转改密页面
- 不改密无法进行其他操作
- 新密码符合复杂度要求（8 位以上，含大小写字母 + 数字 + 特殊字符，至少 3 类）

## 3. 功能详情

### 3.1 教务端账号登录

**功能描述**:
- 用户输入用户名和密码
- 系统验证账号密码（从 `sys_internal_user` 表验证）
- 验证通过后生成登录凭证
- 记录登录日志

**输入**:
- 用户名
- 密码

**输出**:
- 登录成功：返回用户信息、登录凭证
- 登录失败：返回错误原因

**业务规则**:
- 密码验证失败时不提示具体是账号还是密码错误
- 账号被禁用时明确提示
- 首次登录强制修改密码

### 3.2 教师端账号登录

**功能描述**:
- 教师输入手机号/工号和密码
- 系统验证账号密码（从 `sys_teacher_user` 表验证）
- 验证通过后生成登录凭证
- 记录登录日志

**输入**:
- 手机号或工号
- 密码

**输出**:
- 登录成功：返回教师信息、登录凭证
- 登录失败：返回错误原因

**业务规则**:
- 密码验证失败时不提示具体是账号还是密码错误
- 账号被禁用时明确提示
- 首次登录强制修改密码

### 3.3 小程序用户登录

**功能描述**:
- 用户输入手机号
- 获取短信验证码
- 输入验证码后登录

**输入**:
- 手机号
- 短信验证码

**输出**:
- 登录成功：返回用户信息、登录凭证
- 登录失败：返回错误原因

**业务规则**:
- 验证码有效期 5 分钟
- 手机号不存在时提示账号不存在
- **不自动创建学员账号**（学员账号仅支持后台手动创建）

### 3.4 短信验证码发送

**功能描述**:
- 用户输入手机号请求验证码
- 系统验证手机号格式
- 发送短信验证码

**输入**:
- 手机号
- 验证码用途（登录/注册/重置密码）

**输出**:
- 发送成功：提示验证码已发送
- 发送失败：返回错误原因

**业务规则**:
- 60 秒内只能发送 1 次
- 验证码 6 位数字
- 验证码 5 分钟有效

### 3.5 登录凭证刷新

**功能描述**:
- 登录凭证即将过期时自动刷新
- 用户无感知继续使用系统

**业务规则**:
- 凭证过期前自动刷新
- 刷新后旧凭证失效
- 凭证失效后需重新登录

### 3.6 修改密码

**功能描述**:
- 用户可修改自己的登录密码
- 首次登录强制修改密码

**输入**:
- 旧密码
- 新密码

**输出**:
- 修改成功：提示成功
- 修改失败：返回错误原因

**业务规则**:
- 需验证旧密码
- 新密码需符合复杂度要求（8 位以上，包含大小写字母 + 数字 + 特殊字符，至少 3 类）
- 修改成功后需重新登录

### 3.7 登出

**功能描述**:
- 用户主动退出登录
- 清除登录状态

**业务规则**:
- 登出后凭证立即失效
- 记录登出日志

## 5. 异常处理

| 异常场景 | 提示信息 |
|---------|---------|
| 账号或密码错误 | 账号或密码错误 |
| 账号已被禁用 | 账号已被禁用，请联系管理员 |
| 账号已锁定 | 账号已锁定，请 30 分钟后重试 |
| 验证码错误或已过期 | 验证码错误或已过期，请重新获取 |
| 验证码发送过于频繁 | 发送过于频繁，请稍后再试 |
| 新密码不符合要求 | 密码需 8 位以上，包含大小写字母、数字和特殊字符 |
| 旧密码错误 | 旧密码错误 |
| 登录凭证已过期 | 登录已过期，请重新登录 |
| 手机号未注册 | 该手机号未注册，请联系管理员创建账号 |

## 6. 安全要求

1. **密码存储**: 密码必须 BCrypt 加密存储，不可明文
2. **密码复杂度**: 8 位以上，包含大小写字母 + 数字 + 特殊字符（至少 3 类）
3. **登录失败限制**: 5 次失败后锁定 30 分钟
4. **凭证有效期**: 登录凭证需设置合理有效期
5. **HTTPS**: 生产环境必须使用 HTTPS
6. **敏感信息**: 不返回密码等敏感信息
