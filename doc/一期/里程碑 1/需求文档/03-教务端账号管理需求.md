# 03-教务端账号管理需求

**优先级**: P0  
**涉及端**: 后端、教务端  
**更新日期**: 2026-03-25

---

## 1. 功能概述

实现教务端账号的 CRUD 管理，支持管理员、教务运营账号的全生命周期管理。

**设计原则**:
- 教务端账号与教师端账号为**两套独立的账号体系**
- 教务端账号使用 `sys_internal_user` 表
- 教师端账号使用 `sys_teacher_user` 表（详见 `07-教师账号管理需求.md`）

**用户分类**:
| 类型 | 角色 | 管理方式 | 校区关系 | 使用端 |
|-----|------|---------|---------|-------|
| **教务端账号** | ADMIN、OPERATOR | 完整生命周期管理 | 可属于多个校区 | 教务端 |
| **学员用户** | STUDENT | 仅支持后台手动创建 | 仅属于一个校区 | 小程序 |

**设计原则**:
- 教务端账号与校区为 **多对多** 关系（一个用户可属于多个校区）
- 学员用户与校区为 **一对一** 关系（一个学员仅属于一个校区）
- 角色不关联校区，仅定义功能权限
- 数据权限在用户级别配置

**适用范围**:
- ✅ 教务端 - 账号管理配置入口
- ❌ 教师端 - 教师账号独立管理（详见 `07-教师账号管理需求.md`）
- ❌ 学员端 - 仅可查看/编辑个人信息

## 2. 教务端账号管理

### 2.1 用户故事

#### 2.1.1 用户列表查询

**作为** 系统管理员  
**我希望** 查看系统用户列表  
**以便** 管理用户账号

**验收标准**:
- 支持分页查询
- 支持按姓名/手机号/角色搜索
- 支持按状态筛选
- 显示用户基本信息和绑定校区

#### 2.1.2 用户创建

**作为** 系统管理员  
**我希望** 创建新用户  
**以便** 为员工分配系统账号

**验收标准**:
- 可创建管理员/教务账号
- 可分配角色
- 可设置初始密码
- 可绑定多个校区
- 账号创建成功后可登录

#### 2.1.3 用户编辑

**作为** 教务管理员  
**我希望** 编辑用户信息  
**以便** 更新用户资料

**验收标准**:
- 可修改基本信息（姓名、手机号、头像）
- ADMIN 可调整角色
- 可调整校区绑定
- 教务不可删除用户

#### 2.1.4 用户禁用/启用

**作为** 系统管理员  
**我希望** 禁用/启用用户账号  
**以便** 控制用户访问权限

**验收标准**:
- 禁用后用户无法登录
- 禁用后登录凭证立即失效
- 可重新启用账号

#### 2.1.5 密码重置

**作为** 系统管理员  
**我希望** 重置用户密码  
**以便** 帮助用户恢复账号访问

**验收标准**:
- 重置后生成临时密码
- 临时密码通过短信发送
- 用户首次登录需修改密码

### 2.2 功能详情

#### 2.2.1 用户列表查询

**功能描述**:
- 分页展示教务端用户列表
- 支持搜索和筛选
- 显示用户基本信息

**查询条件**:
- 关键词（姓名/手机号）
- 角色（ADMIN/OPERATOR）
- 状态（ACTIVE/INACTIVE/LOCKED/PENDING）
- 校区（按绑定校区筛选）

**列表字段**:
- 用户 ID
- 用户名
- 姓名
- 手机号
- 头像
- 角色
- 状态
- 绑定校区（显示主要校区）
- 创建时间
- 最后登录时间

#### 2.2.2 用户创建

**功能描述**:
- 填写用户基本信息
- 分配角色
- 设置初始密码
- 绑定校区（可多选）

**输入信息**:
| 字段 | 必填 | 说明 |
|-----|------|------|
| 用户名 | ✅ | 登录用户名（唯一） |
| 姓名 | ✅ | 真实姓名 |
| 手机号 | ✅ | 手机号（唯一） |
| 角色 | ✅ | ADMIN/OPERATOR |
| 邮箱 | ❌ | - |
| 绑定校区 | ⚠️ | 可多选 |
| 备注 | ❌ | 内部备注信息 |

**初始密码策略**:
- 系统自动生成随机初始密码（12 位，包含大小写字母 + 数字 + 特殊字符，至少 3 类）
- 创建时显示一次，需管理员自行记录并交付给用户
- 首次登录强制修改密码
- 初始密码 7 天内有效，逾期需管理员重置

**业务规则**:
- 用户名必须唯一
- 手机号必须唯一
- ADMIN 仅 ADMIN 可创建
- 支持绑定多个校区

#### 2.2.3 用户编辑

**功能描述**:
- 修改用户基本信息
- 调整角色（仅 ADMIN）
- 调整校区绑定

**可修改信息**:
| 字段 | ADMIN | OPERATOR | 说明 |
|-----|-------|----------|------|
| 姓名 | ✅ | ✅ | 所有角色可编辑 |
| 手机号 | ✅ | ✅ | 需验证唯一性 |
| 邮箱 | ✅ | ✅ | - |
| 头像 | ✅ | ✅ | - |
| 角色 | ✅ | ❌ | 仅 ADMIN 可修改他人角色 |
| 校区绑定 | ✅ | ❌ | 仅 ADMIN 可修改 |
| 账号状态 | ✅ | ❌ | 仅 ADMIN 可修改 |

**业务规则**:
- 用户名不可修改
- 手机号修改后需验证唯一性
- 不可删除最后一个 ADMIN 账号

#### 2.2.4 用户删除

**功能描述**:
- 软删除用户账号
- 30 天内可恢复

**删除规则**:
| 角色 | 删除规则 |
|-----|---------|
| ADMIN | 不可删除最后一个 ADMIN 账号 |
| OPERATOR | 有进行中的操作时不可删除 |

**删除策略**: 
- 默认采用软删除，30 天内可恢复，逾期永久删除
- 历史操作记录、日志等关联数据保留

#### 2.2.5 用户状态管理

**状态类型**:
| 状态 | 说明 | 触发条件 | 恢复方式 |
|-----|------|---------|---------|
| ACTIVE | 正常 | 默认状态 | - |
| INACTIVE | 禁用 | 管理员手动禁用 | 管理员启用 |
| LOCKED | 锁定 | 登录失败 5 次 | 30 分钟后自动解锁/管理员解锁 |
| PENDING | 待激活 | 账号创建后 | 用户首次登录修改密码 |

#### 2.2.6 批量操作

- **批量导入**: 支持 Excel/CSV 文件批量导入内部账号
- **批量导出**: 支持导出用户列表为 Excel/CSV 文件
- **批量禁用/启用**: 选中多个账号批量操作

**导入模板字段**:
| 字段 | 必填 | 说明 |
|-----|------|------|
| 姓名 | ✅ | - |
| 手机号 | ✅ | 需符合格式，不可重复 |
| 角色 | ✅ | ADMIN/OPERATOR |
| 用户名 | ❌ | 不填则自动生成（手机号@chordsked.com） |
| 邮箱 | ❌ | - |
| 绑定校区 | ❌ | 填写校区编码，多个用逗号分隔 |

### 2.3 登录与安全

**认证方式**:
| 认证方式 | 说明 | 适用角色 |
|---------|------|---------|
| 账号密码 | 用户名 + 密码 | 所有教务端用户 |

**密码策略**:
- 最小长度：8 位
- 复杂度：包含大小写字母 + 数字 + 特殊字符（至少 3 类）
- 加密存储
- 登录失败限制：5 次失败后锁定 30 分钟
- 密码有效期：90 天强制更换（可配置）

## 3. 学员用户管理

### 3.1 学员账号创建

**当前仅支持后台手动创建**。

| 创建方式 | 触发场景 | 说明 |
|---------|---------|------|
| 后台手动创建 | 教务人员在后台创建 | 唯一方式 |

> **注**: 团购订单核销自动创建、小程序自主注册为二期功能。

#### 3.1.2 后台手动创建学员

**功能描述**:
- 教务人员在后台手动创建学员账号
- 支持批量导入

**输入信息**:
| 字段 | 必填 | 说明 |
|-----|------|------|
| 姓名 | ✅ | 学员姓名 |
| 手机号 | ✅ | 手机号（唯一，登录账号） |
| 校区 | ✅ | 选择所属校区（仅单选） |
| 性别 | ❌ | 男/女 |
| 出生日期 | ❌ | - |
| 分配教师 | ❌ | 可选，后续可调整 |
| 备注 | ❌ | 内部备注信息 |

**业务规则**:
- 手机号必须唯一
- 校区必须选择（仅单选）
- 创建后自动发送短信通知（含登录方式）

#### 3.1.3 学员账号编辑

**可修改信息**:
| 字段 | 后台 | 学员自己 | 说明 |
|-----|------|---------|------|
| 姓名 | ✅ | ✅ | 可修改 |
| 手机号 | ✅ | ❌ | 后台可修改，需验证唯一性 |
| 校区 | ✅ | ❌ | 后台可调整 |
| 分配教师 | ✅ | ❌ | 后台可调整 |
| 性别 | ✅ | ✅ | - |
| 出生日期 | ✅ | ✅ | - |
| 学习目标 | ✅ | ✅ | - |

#### 3.1.4 学员账号状态

| 状态 | 说明 | 触发条件 | 恢复方式 |
|-----|------|---------|---------|
| ACTIVE | 正常 | 默认状态 | - |
| INACTIVE | 禁用 | 后台手动禁用 | 后台启用 |

**禁用场景**:
- 违规操作（恶意刷课、虚假评价等）
- 账号异常（疑似被盗、异常登录）
- 用户申请注销账号

#### 3.1.5 批量操作

- **批量导入**: 支持 Excel/CSV 文件批量导入学员账号
- **批量导出**: 支持导出学员列表为 Excel/CSV 文件

**导入模板字段**:
| 字段 | 必填 | 说明 |
|-----|------|------|
| 姓名 | ✅ | - |
| 手机号 | ✅ | 需符合格式，不可重复 |
| 校区 | ✅ | 填写校区编码或名称（单选） |
| 性别 | ❌ | 男/女 |
| 出生日期 | ❌ | YYYY-MM-DD 格式 |
| 分配教师 | ❌ | 填写教师姓名或工号 |
| 学习乐器 | ❌ | - |
| 当前水平 | ❌ | - |

## 5. 异常处理

| 异常场景 | 提示信息 |
|---------|---------|
| 用户名已存在 | 用户名已存在，请更换 |
| 手机号已存在 | 手机号已被使用，请更换或合并账号 |
| 角色不存在 | 角色不存在，请检查 |
| 用户不存在 | 用户不存在 |
| 不能删除自己 | 不能删除当前登录账号 |
| 不能禁用自己 | 不能禁用当前登录账号 |
| 最后一个 ADMIN | 不能删除/禁用最后一个管理员账号 |

## 6. 安全要求

1. **密码安全**: 密码必须加密存储，8 位以上，包含大小写字母 + 数字 + 特殊字符（至少 3 类）
2. **操作审计**: 用户创建、禁用、密码重置操作必须记录日志
3. **数据权限**: 用户列表查询应遵循数据权限隔离
4. **敏感操作**: 密码重置需二次确认
5. **登录限制**: 5 次登录失败后锁定 30 分钟
