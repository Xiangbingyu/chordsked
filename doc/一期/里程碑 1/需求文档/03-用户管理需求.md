# 03-用户管理需求

**优先级**: P0  
**涉及端**: 后端、教务端

---

## 1. 功能概述

实现系统用户的 CRUD 管理，支持用户创建、编辑、禁用、密码重置等功能。

**适用范围**:
- ✅ 教务端 - 用户管理配置入口
- ❌ 教师端 - 仅可查看/编辑个人信息
- ❌ 学员端 - 仅可查看/编辑个人信息

---

## 2. 用户故事

### 2.1 用户列表查询

**作为** 教务管理员  
**我希望** 查看系统用户列表  
**以便** 管理用户账号

**验收标准**:
- 支持分页查询
- 支持按姓名/手机号/角色搜索
- 支持按状态筛选
- 显示用户基本信息和角色

### 2.2 用户创建

**作为** 系统管理员  
**我希望** 创建新用户  
**以便** 为员工分配系统账号

**验收标准**:
- 可创建管理员/教务/教师/学员账号
- 可分配角色
- 可设置初始密码
- 账号创建成功后可登录

### 2.3 用户编辑

**作为** 教务管理员  
**我希望** 编辑用户信息  
**以便** 更新用户资料

**验收标准**:
- 可修改基本信息（姓名、手机号、头像）
- 可调整角色
- 教务不可删除用户

### 2.4 用户禁用/启用

**作为** 系统管理员  
**我希望** 禁用/启用用户账号  
**以便** 控制用户访问权限

**验收标准**:
- 禁用后用户无法登录
- 禁用后登录凭证立即失效
- 可重新启用账号

### 2.5 密码重置

**作为** 系统管理员  
**我希望** 重置用户密码  
**以便** 帮助用户恢复账号访问

**验收标准**:
- 重置后生成临时密码
- 临时密码通过短信发送
- 用户首次登录需修改密码

## 3. 功能详情

### 3.1 用户列表查询

**功能描述**:
- 分页展示用户列表
- 支持搜索和筛选
- 显示用户基本信息

**查询条件**:
- 关键词（姓名/手机号）
- 角色
- 状态（启用/禁用）
- 校区

**列表字段**:
- 用户 ID
- 用户名
- 姓名
- 手机号
- 头像
- 角色列表
- 状态
- 校区
- 创建时间

### 3.2 用户创建

**功能描述**:
- 填写用户基本信息
- 分配角色
- 设置初始密码

**输入信息**:
- 用户名（后台用户必填）
- 密码（后台用户必填）
- 姓名
- 手机号
- 角色（可多选）
- 校区
- 首次登录需改密（是/否）

**业务规则**:
- 用户名必须唯一
- 手机号必须唯一
- 密码需符合复杂度要求

### 3.3 用户编辑

**功能描述**:
- 修改用户基本信息
- 调整角色

**可修改信息**:
- 姓名
- 手机号
- 头像
- 角色
- 校区

**业务规则**:
- 用户名不可修改
- 手机号修改后需验证唯一性

### 3.4 用户禁用/启用

**功能描述**:
- 禁用用户账号
- 启用已禁用的账号

**业务规则**:
- 禁用后用户无法登录
- 禁用后现有登录凭证失效
- 不能禁用自己（当前登录用户）

### 3.5 密码重置

**功能描述**:
- 管理员重置用户密码
- 生成临时密码并发送给用户

**业务规则**:
- 临时密码通过短信发送
- 用户首次登录需修改密码
- 重置后现有登录凭证失效

### 3.6 用户详情

**功能描述**:
- 查看用户完整信息
- 查看用户角色
- 查看登录记录

**展示信息**:
- 基本信息
- 角色信息
- 校区信息
- 状态
- 创建时间、更新时间
- 最后登录时间

- 校区：`type = 'CAMPUS'`，`level = 1`
- 部门：`type = 'DEPT'`，`level = 2`
- 小组：`type = 'GROUP'`，`level = 3`

## 5. 异常处理

| 异常场景 | 提示信息 |
|---------|---------|
| 用户名已存在 | 用户名已存在，请更换 |
| 手机号已存在 | 手机号已被使用，请更换或合并账号 |
| 角色不存在 | 角色不存在，请检查 |
| 用户不存在 | 用户不存在 |
| 不能删除自己 | 不能删除当前登录账号 |
| 不能禁用自己 | 不能禁用当前登录账号 |

## 6. 前端页面要求

### 6.1 用户列表页面

**功能**:
- 表格展示用户列表
- 支持分页
- 支持搜索（姓名/手机号）
- 支持筛选（角色、状态、校区）
- 操作列：编辑、禁用/启用、密码重置、详情

### 6.2 用户创建/编辑表单

**字段**:
- 用户名（仅创建时）
- 密码（仅创建时）
- 姓名
- 手机号
- 头像（上传）
- 角色（多选）
- 校区（下拉选择）
- 首次登录需改密（复选框）

### 6.3 用户详情页面

**展示信息**:
- 基本信息（用户名、姓名、手机号、头像）
- 角色信息
- 校区信息
- 状态
- 创建时间、更新时间
- 最后登录时间

---

## 7. 安全要求

1. **密码安全**: 密码必须加密存储
2. **操作审计**: 用户创建、禁用、密码重置操作必须记录日志
3. **数据权限**: 用户列表查询应遵循数据权限隔离
4. **敏感操作**: 密码重置需二次确认
