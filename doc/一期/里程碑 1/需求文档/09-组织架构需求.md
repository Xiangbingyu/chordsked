## 1. 概述

本里程碑定义 ChordSked 吉他教育课程管理系统的组织架构体系。

### 1.1 核心设计原则

> **校区与组织架构分离** - 两者是 2 个独立的模块

- **组织架构**：定义公司内部的部门结构、汇报关系、岗位体系
- **校区**：定义物理/逻辑的教学场所、资源分配、业务运营单元

两者独立设计，通过关联表建立映射关系，支持灵活的组织形态。

## 2. 组织架构模块

### 2.1 组织单元类型

| 类型代码 | 类型名称 | 说明 | 示例 |
|---------|---------|------|------|
| `HQ` | 总部 | 公司最高层级 | ChordSked 总部 |
| `DEPT` | 部门 | 职能管理部门 | 教务处、市场部、人力资源部 |

## 3. 校区模块

### 3.1 校区定义

校区是独立的业务运营单元，与组织架构解耦：

| 属性 | 说明 |
|-----|------|
| **独立性** | 校区可独立核算、独立运营 |
| **多对多** | 一个员工可属于多个校区，一个校区可有多名员工 |
| **资源绑定** | 教室、设备等物理资源绑定到校区 |
| **业务隔离** | 学员、课程、订单按校区隔离 |

### 3.2 校区实体设计

```typescript
interface Campus {
  id: string;                    // 校区 ID
  name: string;                  // 校区名称
  code: string;                  // 校区编码（唯一）
```

## 4. 组织架构与校区的关联

### 4.1 关联设计原则

- **松耦合**：组织架构和校区独立维护，通过关联表建立关系
- **灵活性**：支持一人多校区、一校区多部门
- **时效性**：关联关系支持有效期，支持历史追溯

### 4.2 组织 - 校区关联表

```typescript
interface OrgCampusRelation {
  id: string;                    // 关联 ID
  orgUnitId: string;             // 组织单元 ID
  campusId: string;              // 校区 ID
  relationType: RelationType;    // 关联类型
  startDate: Date;               // 生效日期
  endDate?: Date;                // 失效日期（为空表示长期有效）
  isPrimary: boolean;            // 是否主属校区
  metadata?: Record<string, any>; // 扩展元数据
  createdAt: Date;
  updatedAt: Date;
}

enum RelationType {
  MANAGES = 'MANAGES',           // 管理（部门管理校区）
  SERVES = 'SERVES',             // 服务（团队服务校区）
  LOCATED = 'LOCATED',           // 驻地（团队驻点校区）
  OWNS = 'OWNS'                  // 归属（资源归属校区）
}
```

## 5. 数据权限设计

### 5.1 基于组织架构的数据权限

| 组织层级 | 数据可见范围 | 说明 |
|---------|------------|------|
| 总部 (HQ) | 全系统数据 | 所有部门、所有校区 |
| 部门 (DEPT) | 本部门 + 下级部门数据 | 教务处可查看所有教学相关数据 |
| 团队 (TEAM) | 本团队数据 | 教研一组仅查看本组数据 |
| 岗位 (POSITION) | 个人数据 | 教师仅查看已分配学员 |

### 5.2 基于校区的数据权限

> **注意**：账号与校区的绑定关系、角色分配在账号管理模块统一配置，本模块仅提供校区数据基础结构。

| 校区角色 | 数据可见范围 | 说明 |
|---------|------------|------|
| 校区负责人 | 本校区全部数据 | 学员、教师、课程、营收 |
| 授课教师 | 本校区已分配学员 | 仅教授学员信息 |
| 工作人员 | 本校区操作权限 | 核销、排课等操作权限 |

### 5.3 复合权限校验

```
权限校验 = 组织权限 ∩ 校区权限

示例：
- 教师 A 属于「教务处→教研团队」，主属校区为「北京校区」
- 组织权限：可查看教研团队数据
- 校区权限：可查看北京校区学员数据
- 最终权限：可查看北京校区 + 教研团队交集的学员数据
```

## 6. 典型场景

### 6.1 场景 1：跨校区授课教师

```
教师张三：
- 组织架构：总部 → 教务处 → 教研一组 → 高级教师
- 校区绑定（在账号管理模块配置）:
  - 北京校区（主属，80% 课时）
  - 上海校区（兼职，20% 课时）

权限：
- 可查看北京校区和上海校区的已分配学员
- 课时统计按校区分别计算
- KPI 汇总时合并两个校区数据
```

### 6.2 场景 2：总部部门管理多校区

```
教务处：
- 组织架构：总部 → 教务处（部门级）
- 校区关联（在账号管理模块配置）:
  - 管理北京校区
  - 管理上海校区
  - 管理广州校区

权限：
- 可查看所有关联校区的数据
- 可跨校区调配教师资源
- 可制定统一的教学标准
```

### 6.3 场景 3：新校区筹备

```
新校区（筹备中）：
- 校区状态：PLANNING
- 组织架构关联（在账号管理模块配置）:
  - 市场部→线下推广组（负责招生）
  - 教务处→排课团队（负责排课）
  - 人力资源部→招聘组（负责招聘）

权限：
- 各团队仅可访问筹备相关数据
- 正式开业后切换为正常运营权限
```

## 7. 数据库设计

### 7.1 核心表结构

```sql
-- 组织单元表
CREATE TABLE org_units (
  id            VARCHAR(36) PRIMARY KEY,
  name          VARCHAR(100) NOT NULL,
  type          ENUM('HQ', 'DEPT', 'TEAM', 'POSITION') NOT NULL,
  parent_id     VARCHAR(36) NULL,
  code          VARCHAR(50) UNIQUE NOT NULL,
  description   TEXT NULL,
  manager_id    VARCHAR(36) NULL,
  sort_order    INT DEFAULT 0,
  status        ENUM('ACTIVE', 'INACTIVE') DEFAULT 'ACTIVE',
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (parent_id) REFERENCES org_units(id),
  INDEX idx_parent (parent_id),
  INDEX idx_type (type)
);

-- 员工 - 组织关系表
CREATE TABLE employee_org_relations (
  id            VARCHAR(36) PRIMARY KEY,
  user_id       VARCHAR(36) NOT NULL,
  org_unit_id   VARCHAR(36) NOT NULL,
  is_primary    BOOLEAN DEFAULT FALSE,
  joined_at     DATE NOT NULL,
  left_at       DATE NULL,
  title         VARCHAR(100) NULL,
  status        ENUM('ACTIVE', 'INACTIVE') DEFAULT 'ACTIVE',
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (org_unit_id) REFERENCES org_units(id),
  UNIQUE KEY uk_user_org (user_id, org_unit_id),
  INDEX idx_user (user_id)
);

-- 校区表
CREATE TABLE campuses (
  id            VARCHAR(36) PRIMARY KEY,
  name          VARCHAR(100) NOT NULL,
  code          VARCHAR(50) UNIQUE NOT NULL,
  type          ENUM('FLAGSHIP', 'STANDARD', 'STUDIO', 'ONLINE', 'PARTNER') NOT NULL,
  address       VARCHAR(500) NULL,
  latitude      DECIMAL(10, 8) NULL,
  longitude     DECIMAL(11, 8) NULL,
  phone         VARCHAR(20) NULL,
  manager_id    VARCHAR(36) NULL,
  status        ENUM('ACTIVE', 'INACTIVE', 'PLANNING') DEFAULT 'PLANNING',
  open_date     DATE NULL,
  close_date    DATE NULL,
  settings      JSON NULL,
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_status (status),
  INDEX idx_type (type)
);

-- 组织 - 校区关联表
CREATE TABLE org_campus_relations (
  id            VARCHAR(36) PRIMARY KEY,
  org_unit_id   VARCHAR(36) NOT NULL,
  campus_id     VARCHAR(36) NOT NULL,
  relation_type ENUM('MANAGES', 'SERVES', 'LOCATED', 'OWNS') NOT NULL,
  start_date    DATE NOT NULL,
  end_date      DATE NULL,
  is_primary    BOOLEAN DEFAULT FALSE,
  metadata      JSON NULL,
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (org_unit_id) REFERENCES org_units(id),
  FOREIGN KEY (campus_id) REFERENCES campuses(id),
  UNIQUE KEY uk_org_campus (org_unit_id, campus_id, relation_type),
  INDEX idx_campus (campus_id)
);

-- 教室表
CREATE TABLE classrooms (
  id            VARCHAR(36) PRIMARY KEY,
  campus_id     VARCHAR(36) NOT NULL,
  name          VARCHAR(100) NOT NULL,
  type          ENUM('ONE_ON_ONE', 'SMALL_GROUP', 'MEDIUM_GROUP', 'LARGE_GROUP', 'PRACTICE_ROOM', 'MULTI_PURPOSE') NOT NULL,
  capacity      INT NOT NULL,
  status        ENUM('AVAILABLE', 'OCCUPIED', 'MAINTENANCE', 'DISABLED') DEFAULT 'AVAILABLE',
  description   TEXT NULL,
  equipment     JSON NULL,
  floor         INT NULL,
  building      VARCHAR(50) NULL,
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (campus_id) REFERENCES campuses(id),
  INDEX idx_campus (campus_id),
  INDEX idx_status (status),
  INDEX idx_type (type),
  UNIQUE KEY uk_campus_name (campus_id, name)
);

-- 校区资源表（非教室类资源）
CREATE TABLE campus_resources (
  id            VARCHAR(36) PRIMARY KEY,
  campus_id     VARCHAR(36) NOT NULL,
  type          ENUM('INSTRUMENT', 'EQUIPMENT') NOT NULL,
  name          VARCHAR(100) NOT NULL,
  capacity      INT NULL,
  equipment     JSON NULL,
  status        ENUM('AVAILABLE', 'OCCUPIED', 'MAINTENANCE') DEFAULT 'AVAILABLE',
  schedule      JSON NULL,
  created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (campus_id) REFERENCES campuses(id),
  INDEX idx_campus (campus_id),
  INDEX idx_type (type)
);
```
