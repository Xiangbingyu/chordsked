# 05-审计日志需求

**优先级**: P0  
**涉及端**: 后端、教务端

---

## 1. 功能概述

实现系统操作日志的记录、查询和导出，确保所有敏感操作可追溯。

**权限控制说明**:
- 日志模块的权限纳入角色权限配置体系统一管理
- 本模块需要以下权限细分（供角色权限配置参考）

---

## 2. 用户故事

### 2.1 日志记录

**作为** 系统  
**我希望** 自动记录关键操作  
**以便** 后续审计和追溯

**验收标准**:
- 登录/登出操作自动记录
- 权限修改操作自动记录
- 数据导出操作自动记录
- 敏感操作（删除/禁用/密码重置）自动记录

### 2.2 日志查询

**作为** 系统管理员  
**我希望** 查询操作日志  
**以便** 审计用户行为

**验收标准**:
- 支持分页查询
- 支持按操作人、操作类型、时间范围筛选
- 支持关键词搜索
- 显示操作详情
- 权限控制：需要日志查询权限（由角色权限配置）

### 2.3 日志导出

**作为** 系统管理员  
**我希望** 导出操作日志  
**以便** 存档或进一步分析

**验收标准**:
- 支持 Excel 格式导出
- 导出操作本身记录日志
- 权限控制：需要日志导出权限（由角色权限配置）

### 2.4 敏感日志访问控制

**作为** 系统管理员  
**我希望** 限制敏感日志的访问  
**以便** 保护敏感信息

**验收标准**:
- 权限修改日志仅管理员可见
- 敏感操作日志仅管理员可见
- 普通用户仅能查看自己的操作日志
- 权限控制：需要敏感日志访问权限（由角色权限配置）

---

## 3. 功能详情

### 3.0 权限细分说明

**说明**: 日志模块的权限纳入角色权限配置体系统一管理，以下为日志模块需要的权限细分，供角色权限配置时参考。

**权限细分**:

| 权限代码 | 权限名称 | 权限类型 | 说明 | 默认角色 |
|---------|---------|---------|------|---------|
| `menu:log` | 审计日志菜单 | 菜单权限 | 访问审计日志页面 | 管理员、教务运营 |
| `log:view` | 查看日志列表 | 按钮权限 | 访问日志列表页面 | 管理员、教务运营 |
| `log:export` | 导出日志 | 按钮权限 | 导出日志为 Excel 文件 | 管理员 |
| `log:sensitive` | 查看敏感日志 | **按钮权限** | 查看敏感操作日志（权限修改、密码重置等） | 管理员 |
| `log:detail` | 查看日志详情 | 按钮权限 | 查看单条日志的详细信息 | 管理员、教务运营 |

**权限树结构**:
```
审计日志 (menu:log)
├── 查看日志列表 (log:view)
├── 查看日志详情 (log:detail)
├── 导出日志 (log:export)
└── 查看敏感日志 (log:sensitive)
```

**数据权限规则** (自动处理，无需配置):
- 普通用户仅能查看自己的操作日志
- 管理员可查看全系统日志
- 校区负责人仅可查看本校区日志

**配置入口**: 教务端 → 角色管理 → 权限配置 → 审计日志模块

### 3.1 日志记录

**功能描述**:
- 自动记录用户关键操作
- 记录操作人、时间、内容等信息

**记录内容**:
- 操作人 ID、姓名
- 操作时间
- 操作模块、类型
- 请求参数
- 操作结果
- 操作 IP

**必须记录的操作**:
- 登录/登出
- 修改密码
- 创建/编辑/删除用户
- 禁用/启用用户
- 密码重置
- 创建/编辑/删除角色
- 配置角色权限
- 导入订单
- 核销订单
- 导出数据

### 3.2 日志列表查询

**功能描述**:
- 分页展示操作日志
- 支持筛选和搜索

**查询条件**:
- 模块
- 操作类型
- 操作人
- 时间范围
- 关键词

**列表字段**:
- 日志 ID
- 模块
- 操作类型
- 操作人
- 操作 IP
- 操作结果
- 操作时间
- 执行时长

### 3.3 日志详情查询

**功能描述**:
- 查看单条日志的详细信息

**展示信息**:
- 模块、操作类型
- 操作人、操作时间
- 操作 IP
- 请求参数
- 操作结果
- 执行时长

### 3.4 日志导出

**功能描述**:
- 导出日志为 Excel 文件
- 支持筛选条件导出

**业务规则**:
- 导出操作本身记录日志
- 大数据量时异步处理

### 3.5 登录日志查询

**功能描述**:
- 单独查询登录/登出日志
- 展示用户登录情况

**列表字段**:
- 用户 ID
- 用户名
- 操作类型（登录/登出）
- 登录 IP
- 操作结果
- 操作时间

## 4. 数据要求

### 4.1 操作日志表 (sys_operation_log)

| 字段 | 类型 | 长度 | 必填 | 约束 | 说明 |
|-----|------|------|-----|------|------|
| id | BIGINT | - | 是 | 主键 | 日志 ID |
| module | VARCHAR | 50 | 是 | 索引 | 模块名称 |
| operation | VARCHAR | 50 | 是 | 索引 | 操作类型 |
| operator_id | BIGINT | - | 是 | 索引 | 操作人 ID |
| operator_name | VARCHAR | 50 | 是 | - | 操作人姓名 |
| ip | VARCHAR | 50 | 是 | - | 操作 IP |
| user_agent | VARCHAR | 200 | 否 | - | 用户代理 |
| params | TEXT | - | 否 | - | 请求参数（JSON） |
| result | VARCHAR | 20 | 是 | - | 结果（SUCCESS/FAILED） |
| message | VARCHAR | 500 | 否 | - | 返回消息 |
| duration | INT | - | 否 | - | 执行时长（ms） |
| created_at | DATETIME | - | 是 | 索引 | 操作时间 |

### 4.2 登录日志表 (sys_login_log)

详见 `01-认证模块需求.md` - 登录日志表结构

| 日志类型 | 保留期限 |
|---------|---------|
| 登录日志 | 180 天 |
| 操作日志 | 365 天 |

|---------|---------|

---

## 8. 安全要求

1. **日志不可篡改**: 日志记录后不可修改
2. **敏感信息脱敏**: 密码等敏感信息不记录或脱敏
3. **访问控制**: 仅管理员可查询日志
4. **导出审计**: 导出操作本身必须记录日志
