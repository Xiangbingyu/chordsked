# 07-教师账号管理需求

**优先级**: P0  
**涉及端**: 后端、教务端

---

## 1. 功能概述

实现教师账号的独立管理，教师账号与教务端账号为两套独立的账号体系。

**设计原则**:
- 三套账号体系完全独立：教务端、教师端、学员端
- 教师账号使用 `sys_teacher_user` 表，与教务端账号（`sys_internal_user`）完全独立
- 教师账号默认拥有教师端（PC Web + 小程序）的使用权限，无需额外配置
- 教师账号不需要角色配置，数据权限固定为"本人"
- 教师与校区为一对一关系（在 `sys_teacher_user` 表中直接存储 `campus_id`）

**适用范围**:
- ✅ 教务端 - 教师账号管理配置入口
- ✅ 教师端（PC Web + 小程序）- 教师登录使用
- ❌ 学员端 - 不适用

## 2. 教师账号字段

| 字段 | 必填 | 类型 | 说明 |
|-----|------|------|------|
| 教师姓名 | ✅ | 文本 | 教师真实姓名 |
| 工号 | ✅ | 文本 | 教师工号（唯一） |
| 联系方式 | ✅ | 手机号 | 手机号（唯一，登录账号） |
| 授课类型 | ✅ | 枚举 | 一对一/小班/大班/全部 |
| 教师等级 | ✅ | 枚举 | 初级/中级/高级/资深 |
| 所属校区 | ✅ | 单选 | 教师所属校区（一对一） |
| 状态 | ✅ | 枚举 | 在职/离职/停用 |
| 教学资历 | ❌ | 文本 | 教学年限、资质证书等 |
| 擅长曲目 | ❌ | 文本 | 擅长教学的曲目列表 |

**字段说明**:

| 字段 | 详细说明 | 选项值 |
|-----|---------|-------|
| 授课类型 | 教师可授课的班级类型 | 一对一、小班（2-6 人）、大班（7 人以上）、全部 |

| 所属校区 | 教师归属的校区 | 从校区列表单选 |
| 状态 | 教师在职状态 | 在职、离职、停用 |

## 3. 用户故事

### 3.1 教师列表查询

**作为** 教务管理员  
**我希望** 查看系统教师列表  
**以便** 管理教师账号

**验收标准**:
- 支持分页查询
- 支持按姓名/工号/手机号搜索
- 支持按校区、授课类型、教师等级、状态筛选
- 显示教师基本信息

### 3.2 教师账号创建

**作为** 教务管理员  
**我希望** 创建新教师账号  
**以便** 为新入职教师分配系统账号

**验收标准**:
- 填写教师基本信息
- 设置初始密码
- 账号创建成功后可登录教师端
- 工号和手机号必须唯一

### 3.3 教师账号编辑

**作为** 教务管理员  
**我希望** 编辑教师信息  
**以便** 更新教师资料

**验收标准**:
- 可修改除工号外的所有字段
- 可重置密码
- 可调整教师状态

### 3.4 教师账号禁用/启用

**作为** 教务管理员  
**我希望** 禁用/启用教师账号  
**以便** 控制教师访问权限

**验收标准**:
- 禁用后教师无法登录
- 禁用后登录凭证立即失效
- 可重新启用账号

### 3.5 教师账号删除

**作为** 教务管理员  
**我希望** 删除离职教师账号  
**以便** 清理系统数据

**验收标准**:
- 有进行中的课程/学员时不可删除
- 删除操作需二次确认
- 采用软删除，可恢复

## 4. 功能详情

### 4.1 教师列表查询

**功能描述**:
- 分页展示教师列表
- 支持搜索和筛选
- 显示教师基本信息

**查询条件**:
- 关键词（姓名/工号/手机号）
- 所属校区
- 授课类型
- 教师等级
- 状态（在职/离职/停用）

**列表字段**:
- 教师 ID
- 教师姓名
- 工号
- 联系方式
- 授课类型
- 教师等级
- 所属校区
- 状态
- 创建时间

### 4.2 教师账号创建

**功能描述**:
- 填写教师基本信息
- 设置初始密码
- 分配所属校区

**输入信息**:
| 字段 | 必填 | 说明 |
|-----|------|------|
| 教师姓名 | ✅ | 真实姓名 |
| 工号 | ✅ | 教师工号（唯一） |
| 联系方式 | ✅ | 手机号（唯一，登录账号） |
| 授课类型 | ✅ | 一对一/小班/大班/全部 |
| 教师等级 | ✅ | 初级/中级/高级/资深 |
| 所属校区 | ✅ | 单选 |
| 教学资历 | ❌ | 教学年限、资质证书等 |
| 擅长曲目 | ❌ | 擅长教学的曲目列表 |
| 初始密码 | ✅ | 系统自动生成或手动设置 |

**初始密码策略**:
- 系统自动生成随机初始密码（12 位，包含大小写字母 + 数字 + 特殊字符，至少 3 类）
- 创建时显示一次，需管理员自行记录并交付给教师
- 首次登录强制修改密码
- 初始密码 7 天内有效，逾期需管理员重置

**业务规则**:
- 工号必须唯一
- 手机号必须唯一
- 所属校区必须选择

### 4.3 教师账号编辑

**功能描述**:
- 修改教师基本信息
- 调整教师状态

**可修改信息**:
| 字段 | 可编辑 | 说明 |
|-----|-------|------|
| 教师姓名 | ✅ | 可修改 |
| 工号 | ❌ | 不可修改 |
| 联系方式 | ✅ | 需验证唯一性 |
| 授课类型 | ✅ | 可调整 |
| 教师等级 | ✅ | 可调整 |
| 所属校区 | ✅ | 可调整 |
| 状态 | ✅ | 在职/离职/停用 |
| 教学资历 | ✅ | 可补充 |
| 擅长曲目 | ✅ | 可补充 |

**业务规则**:
- 工号不可修改
- 手机号修改后需验证唯一性

### 4.4 教师账号删除

**功能描述**:
- 软删除教师账号
- 30 天内可恢复

**删除规则**:
- 有进行中的课程时不可删除
- 有已分配学员时不可删除
- 删除操作需二次确认

**删除策略**: 
- 默认采用软删除，30 天内可恢复，逾期永久删除
- 历史教学记录、学员反馈等关联数据保留

### 4.5 教师账号状态管理

**状态类型**:
| 状态 | 说明 | 触发条件 | 恢复方式 |
|-----|------|---------|---------|
| 在职 | 正常 | 默认状态 | - |
| 离职 | 已离职 | 管理员手动设置 | 管理员修改为在职 |
| 停用 | 临时停用 | 管理员手动设置 | 管理员启用 |

### 4.6 批量操作

- **批量导入**: 支持 Excel/CSV 文件批量导入教师账号
- **批量导出**: 支持导出教师列表为 Excel/CSV 文件
- **批量状态修改**: 选中多个教师批量修改状态

**导入模板字段**:
| 字段 | 必填 | 说明 |
|-----|------|------|
| 教师姓名 | ✅ | - |
| 工号 | ✅ | 需符合格式，不可重复 |
| 联系方式 | ✅ | 需符合格式，不可重复 |
| 授课类型 | ✅ | 一对一/小班/大班/全部 |
| 教师等级 | ✅ | 初级/中级/高级/资深 |
| 所属校区 | ✅ | 填写校区编码或名称 |
| 教学资历 | ❌ | - |
| 擅长曲目 | ❌ | - |

## 5. 教师端登录

### 5.1 登录方式

| 认证方式 | 说明 |
|---------|------|
| 手机号 + 密码 | 手机号 + 初始密码/自定义密码 |
| 手机号 + 验证码 | 手机号 + 短信验证码（可选） |

### 5.2 密码策略

- 最小长度：8 位
- 复杂度：包含大小写字母 + 数字 + 特殊字符（至少 3 类）
- 加密存储
- 登录失败限制：5 次失败后锁定 30 分钟

## 6. 数据要求

### 6.1 教师用户表 (sys_teacher_user)

| 字段 | 类型 | 长度 | 必填 | 约束 | 说明 |
|-----|------|------|-----|------|------|
| id | BIGINT | - | 是 | 主键 | 教师 ID |
| teacher_no | VARCHAR | 50 | 是 | 唯一 | 工号 |
| name | VARCHAR | 50 | 是 | - | 教师姓名 |
| phone | VARCHAR | 20 | 是 | 唯一 | 联系方式（手机号） |
| password | VARCHAR | 100 | 是 | - | 密码（BCrypt 加密） |
| teaching_type | VARCHAR | 20 | 是 | - | 授课类型（ONE_ON_ONE/SMALL/LARGE/ALL） |
| teacher_level | VARCHAR | 20 | 是 | - | 教师等级（JUNIOR/INTERMEDIATE/SENIOR/EXPERT） |
| campus_id | BIGINT | - | 是 | 外键 | 所属校区 ID |
| status | TINYINT | 1 | 是 | 默认 1 | 状态（1 在职/2 离职/3 停用） |
| experience | TEXT | - | 否 | - | 教学资历 |
| good_at | TEXT | - | 否 | - | 擅长曲目 |
| must_change_password | TINYINT | 1 | 是 | 默认 1 | 首次登录需改密 |
| login_fail_count | INT | - | 是 | 默认 0 | 登录失败次数 |
| locked_until | DATETIME | - | 否 | - | 锁定截止时间 |
| last_login_at | DATETIME | - | 否 | - | 最后登录时间 |
| created_at | DATETIME | - | 是 | - | 创建时间 |
| updated_at | DATETIME | - | 是 | - | 更新时间 |
| deleted_at | DATETIME | - | 否 | - | 删除时间（软删除用） |

### 6.2 教师 - 校区关联说明

| 关系类型 | 存储方式 | 说明 |
|---------|---------|------|
| 一对一 | 在 `sys_teacher_user` 表中直接存储 `campus_id` 字段 | 一个教师仅属于一个校区 |

> **设计说明**: 
> - 教师与校区为一对一关系
> - 在 `sys_teacher_user` 表中直接存储 `campus_id` 字段，无需使用 `sys_user_campus` 关联表
> - 教务端账号与校区为多对多关系，使用 `sys_user_campus` 表

## 9. 安全要求

1. **密码安全**: 密码必须 BCrypt 加密存储，8 位以上，包含大小写字母 + 数字 + 特殊字符（至少 3 类）
2. **操作审计**: 教师账号创建、编辑、删除操作必须记录日志
3. **登录限制**: 5 次登录失败后锁定 30 分钟
4. **敏感操作**: 密码重置需二次确认
