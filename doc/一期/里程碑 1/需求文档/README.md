## 📁 文档说明

本目录包含里程碑 1 各功能模块的详细需求说明，用于指导开发和测试。

**涉及端**：
- **教务端**（PC Web 后台管理系统）- 管理员、教务运营
- **教师端**（PC Web）- 教师角色
- **学员端**（微信小程序）- 学员、家长

**权限控制说明**：
- ✅ 教务端 - 需要角色权限控制，权限配置入口
- ✅ 教师端 - 需要角色权限控制，权限由教务端统一配置
- ❌ 学员端 - 不需要角色权限控制，学员拥有所有页面操作权限

## 🔄 流程闭环

### 闭环 1：用户登录认证流程

```
用户输入账号密码 → 后端验证密码 → 生成 JWT+Refresh Token → 返回前端存储
       ▲                                                        │
       │                                                        ▼
       │    登录成功跳转首页 ← 权限加载 ← Token 解析获取用户信息
       └────────────────────────────────────────────────────────┘
```

### 闭环 2：权限校验流程

```
前端发起 API 请求 → 网关拦截验证 Token → 解析角色获取权限 → 权限匹配决定是否放行
                                              │
                    ✅ 通过                    │  ❌ 拒绝
                    ▼                         ▼
               调用业务处理逻辑            返回 403 拒绝访问
```

### 闭环 3：数据权限隔离流程

```
用户查询请求 → 识别角色数据范围 → 动态添加 SQL 过滤条件 → 执行查询返回结果
```

### 闭环 4：学员自动创建流程（后续里程碑）

```
教务录入团购订单 → 核销验证券码/手机号 → 自动生成学员账号 → 下发短信登录凭证
       ▲                                                        │
       │    学员档案完善 ← 绑定课包 ← 转化录入（是否转正）        └────────┘
       └────────────────────────────────────────────────────────────┘
```
