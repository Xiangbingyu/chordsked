## 📋 说明

本文档汇总 ChordSked 系统所有模块的权限点，供角色权限配置时参考。

**权限类型**:
- **菜单权限**: 控制页面访问
- **按钮权限**: 控制页面内操作
- **数据权限**: 控制数据可见范围

**适用范围**:
- ✅ 教务端 - 需要角色权限配置
- ✅ 教师端 - 不需要角色权限配置，拥有所有页面权限，数据自动过滤
- ❌ 学员端 - 不需要权限控制

## 🎯 预置角色权限配置

### 系统管理员 (ADMIN)

拥有所有权限：
```
☑ 所有菜单权限
☑ 所有按钮权限
```

### 教务运营 (OPERATOR)

| 模块 | 权限 |
|-----|------|
| 用户管理 | `menu:user`, `user:view`, `user:update`, `user:enable` |
| 角色管理 | `menu:role`, `role:view` |
| 校区管理 | `menu:campus`, `campus:view` |
| 审计日志 | `menu:log`, `log:view`, `log:detail` |

### 教师 (TEACHER)

**不需要权限配置**，拥有所有页面操作权限，数据自动过滤：
- 学员管理：仅查看已分配学员
- 课表：仅查看本人课表
- 作业：仅查看已分配学员作业

## 📝 使用说明

### 新增权限点

1. 在对应模块的需求文档中添加权限点
2. 更新本文档
3. 在数据库中插入权限记录
4. 在角色权限配置页面中可选

### 权限代码规范

格式：`{模块}:{操作}:{范围}`

示例：
- `user:create:system` - 创建系统用户
- `student:read:assigned` - 查看已分配学员
- `log:export:system` - 导出系统日志

### 权限生效

- 权限配置修改后立即生效
- 用户权限缓存自动清除
- 无需重新登录

### 教师端权限说明

**重要**: 教师端不需要角色权限配置！

- 教师拥有所有页面操作权限
- 数据查询时自动注入过滤条件
- 过滤规则：
  - 学员管理：仅已分配学员
  - 课表：仅本人课程
  - 作业：仅已分配学员
  - KPI：仅本人数据
