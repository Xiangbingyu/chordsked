## 主要功能场景

### 常用术语
  - 第三方平台：具体指美团，大众点评和抖音平台，用户在第三方平台中看到推广信息，可以在第三方平台中直接下单
  - 校区：指线下教学的地点，每个校区有自己的课程、教师和学员档案，目前2个校区，北环国基路和西大剧院
  - 课程类型： 团购体验课、正式课、一对一课程

### 教务/管理员，支持PC端
  -  团购订单转化流程: 
      1. 教务人员直接从第三方平台导出订单
      2. 用户来到线下校区使用第三方平台的券码进行核销，同时提供手机号
      3. 教务人员收集用户信息生成意向学员档案，并创建学员账号
      4. 教务人员引导学员通过学生端小程序预约体验课
      5. 学员在体验课签到，系统记录转化记录，并且将学员和体验课老师进行绑定
  - 排课管理（日历周/月视图）：
      1. 系统搜索可排课时间段，考虑因素：教师可授课时间/承载量(同时间段3-5人)/擅长科目/授课类型、校区教室空置情况、成人/未成年/儿童
      2. 教务人员在可排课时间段选择课程模板（团购体验课/标准课/一对一课程），绑定老师，教室
      3. 如果是一对一课程，需要额外绑定学员
  - 调课/取消处理：学员发起申请（文档中也有“学员不可自己调课”的约束）→ 教务/教师审核 → 生效留痕；取消/补课影响课时规则落账
      1. 学员在小程序端发起调课申请，教务人员审核后生效
      2. 如果是取消课程，需要考虑是否需要退课时
      3. 如果是调整课程，需要帮助学员重新绑定其他同类型课程
      4. 生效留痕
  - 通知与提醒: 团购核销未预约提醒；
  - 校区信息维护：名称、校区教室（作为排课约束性条件）、地址等
  - 课程模板维护：×××老师一对一课程模板、标准课模型版、团购体验课模型版
  - 教师管理：创建教师账号，维护教师档案
  - 学员管：理创建学生账号，维护学生档案
  - 教务管理：账号、角色、权限维护(RABC权限模型)
      1. 创建角色：校区负责人、教务
      2. 为角色设置操作权限，权限树选择，粒度细分到（tab页，操作项）
      3. 为角色设置数据权限，考虑校区
      4. 创建教务账号，并绑定角色
  - 课包管理：创建、编辑、上下架、价格、库存
  - 公告/通知：系统公告、推送通知
  - 数据看板（二期）：
      1. 校区负责人监管：查看教师作业点评/档案完整度等质量指标；异常/低活跃学员清单与到期清单
      2. 实时上课数据、约课情况、老师作业布置情况、学员活跃度、学员课时情况、学员作业完成度、学员练习打卡、续费情况、学员个人信息、学员购课信息

### 教师，支持PC端和小程序端
  - 维护可授课时间/承载量（以及擅长科目、授课类型）
  - 查看个人课表
  - 上课签到（一期可教师代签）→ 自动生成上课记录并触发课时扣减（“上课结束扣除”）
    1. 教师在小程序端或者PC端签到
    2. 教师为本节课学生签到，签到扣除学生课时
    3. 教师对特殊学生调整默认扣减课时
  - 课后反馈：
    1. 教师打开个人课表
    2. 选择已经授课完成的课程，录入课程教学内容和课后回顾
    3. 教师为每个学员填写课堂表现、评语和下节建议
    4. 系统将课后反馈同步到学员成长记录
    5. 教师发布课后作业
  - 作业：
    1. 教师发布作业，包括作业类型（文字、图片、音频、视频），截至四溅
    2. 学生在个人课表中提交作业，判断截止时间
    3. 教师批改作业，包括文字/语音/视频点评
  - 学员管理：已分配学员、学员课时情况、阶段评测报告展示、学员等级标注、作业详情
  - 团购转化节点记录、阶段测评录入
  - 全局看板：今日/本周/本月新增学员数、今日/本周/本月核销数、今日/本周/本月上课节数、即将到期学员提醒、团购核销未预约提醒、作业未提交提醒
  - 数据看板（二期）：查看自己的课时数、上课时长、学员出勤率、完课率、学员满意度评分（第二期）

### 学员，支持小程序端
  - 登录（手机号/微信小程序）→ 查看课表与剩余课时 → 预约体验/团课/正式课（正式课可选老师；团课系统推荐时间）
    1. 使用手机号登录微信小程序
    2. 查看课表
    3. 查看已经购买和可以购买的课包，已经使用的课时
    4. 预约体验/团课/正式课（正式课可选老师；团课系统推荐时间）
  - 课包展示
  - 上课提醒：课前1天+6小时提醒；团购核销未预约提醒；作业未提交提醒；剩余课时提醒
  - 查看课后反馈/成长记录
  - 作业：
    1. 查看老师布置的作业
    2. 提交多媒体作业
    3. 查看批改与点评

## 补充信息

- 团购/体验课程预约登记表，包含以下信息：姓名、年龄、性别、手机号、家长姓名、有无基础、有基础情况说明、意向科目（木吉他、电吉他、贝斯）、学习目的、预期上课时间、预期上课地点、团购课时包、了解渠道、是否有无乐器、报名课时、正式课负责老师、是否转介绍
- 学员档案，包含以下信息：团购/体验课程预约登记表信息、学习目标/进度标签、课包/课时余额、上课记录/作业记录归档、报名时间/缴费金额（所报名后享受的权益）、吉他门类划分（木吉他、电吉他等）
- 教师档案，包括以下信息：姓名、工号、联系方式、入职时间、授课类型、教学资历、擅长曲目（木吉他、电吉他、贝斯），教师等级（S/A/B/C）
- 低活跃学员：连续1月，或每月未完成6课时，连续2周未提交作业
