# 音乐教培机构管理系统 UI/UX 设计文档

## 1. 设计概述
本设计文档旨在为“音乐教培机构综合管理系统”提供统一的视觉风格和用户体验规范。
设计核心理念：**专业、艺术、高效、温暖**。
- **专业**：体现教务管理的严谨性，数据展示清晰准确。
- **艺术**：融入音乐元素，使用优雅的排版和配色，符合艺术教育机构调性。
- **高效**：操作流程扁平化，减少点击次数，特别是高频使用的排课、签到功能。
- **温暖**：通过色彩和微交互（如作业鼓励语、成长记录时间轴），增强学员与机构的情感连接。

## 2. 视觉规范 (Visual Identity)

### 2.1. 色彩体系 (Color Palette)
采用“深蓝+暖橙”的配色方案，兼顾专业感与活力。
*   **主色 (Primary)**: `#1A237E` (深靛蓝) - 代表专业、沉稳、信赖。用于导航栏、重要按钮、标题。
*   **辅助色 (Secondary)**: `#FF6F00` (琥珀金/暖橙) - 代表活力、热情、音乐。用于CTA按钮（预约、支付）、高亮数据、未读消息提醒。
*   **背景色 (Background)**: `#F5F7FA` (浅灰蓝) - 用于页面背景，减少视觉疲劳。
*   **文本色 (Text)**:
    *   主要文本: `#212121` (深灰)
    *   次要文本: `#757575` (中灰)
    *   提示/辅助: `#BDBDBD` (浅灰)
*   **功能色**:
    *   成功: `#4CAF50` (绿色) - 用于签到成功、作业提交成功。
    *   警告: `#FFC107` (黄色) - 用于即将到期提醒、排课冲突提示。
    *   错误: `#F44336` (红色) - 用于操作失败、欠费提醒。

### 2.2. 字体规范 (Typography)
*   **中文字体**: PingFang SC, Microsoft YaHei UI, System-ui
*   **英文字体/数字**: Roboto, Helvetica Neue, Arial (数字使用等宽字体，便于对齐)
*   **字号**:
    *   H1 页面标题: 24px (Bold)
    *   H2 模块标题: 18px (Medium)
    *   正文: 14px (Regular)
    *   辅助文字: 12px (Regular)

### 2.3. 图标与插画
*   使用线性图标（Line Icons），风格简洁现代。
*   在“空状态”（如暂无课程、暂无作业）使用与音乐相关的插画（如吉他、钢琴、音符），缓解用户焦虑。

## 3. 信息架构 (Information Architecture)

### 3.1. 角色视图
系统分为三个端：
1.  **教务管理后台 (Web PC端)**：功能最全，侧重数据录入与统计。
2.  **教师端 (Mobile/Web)**：侧重排课、上课、作业。
3.  **学员端 (Mobile 小程序/H5)**：侧重预约、查看、提交。

### 3.2. 站点地图 (Sitemap)
*   **教务后台**:
    *   工作台 (Dashboard): 待办事项、今日课程概览、数据卡片。
    *   教务管理: 排课管理（日历）、调课审批、教室管理。
    *   学员管理: 学员列表（含搜索/筛选）、学员详情（档案/课程/记录）、公海池（意向学员）。
    *   团购管理: 订单导入、核销记录、转化分析。
    *   财务中心: 订单管理、课消统计。
    *   系统设置: 教师管理、课程设置、权限配置。

*   **教师端**:
    *   首页: 今日课表、待办任务（作业批改/备课）。
    *   日程: 月/周视图排课、请假申请。
    *   学员: 我的学员列表、学员成长记录。
    *   作业: 待批改作业列表、发布作业。
    *   我的: 个人信息、课时统计。

*   **学员端**:
    *   首页: 下节课预告、快速签到、通知公告。
    *   约课: 选课日历、老师介绍、预约确认。
    *   学习: 作业列表（待提交/已批改）、成长档案（时间轴展示）。
    *   我的: 剩余课时、订单记录、个人信息。

## 4. 关键页面交互设计 (Key Interactions)

### 4.1. 智能排课日历 (Schedule Calendar)
*   **视图切换**: 支持月、周、日视图无缝切换。
*   **拖拽排课 (教务端)**: 允许教务在周视图中通过拖拽色块调整课程时间（需二次确认）。
*   **状态标识**: 不同颜色区分课程状态（已预约-蓝色，已签到-绿色，已取消-灰色，冲突-红色条纹）。
*   **悬停预览**: 鼠标悬停在课程块上，浮窗显示课程详情（学员、教室、内容）。

### 4.2. 作业提交与批改 (Homework Flow)
*   **沉浸式提交 (学员端)**:
    *   点击“提交作业” -> 选择类型（视频/音频/图片） -> 调用系统相机/录音 -> 预览/重录 -> 确认上传。
    *   上传过程中显示进度条，支持断点续传。
*   **高效批改 (教师端)**:
    *   左侧/上方播放学员作业（视频/音频），右侧/下方为批改区。
    *   **视频打点**: 播放进度条上支持点击添加“时间点批注”，输入文字或语音，学员点击批注自动跳转对应视频位置。
    *   **快捷评语**: 提供常用评语库（如“节奏稳准”、“手型保持不错”），点击直接填入。

### 4.3. 学员成长档案 (Student Growth Profile)
*   **时间轴设计**: 以垂直时间轴形式展示学员的学习轨迹（入学 -> 第一次上课 -> 第一次作业 -> 考级通过）。
*   **多媒体展示**: 时间轴节点支持嵌入图片、视频封面，点击可展开查看详情。
*   **数据可视化**: 使用雷达图展示学员五维能力（如：节奏感、识谱、技巧、乐感、表现力）。

### 4.4. 团购核销引导 (Group Buy Write-off)
*   **极简核销**: 首页顶部常驻“扫码核销”入口，支持扫二维码或输入券码。
*   **核销后引导**: 核销成功页出现巨大且明显的“立即预约体验课”按钮，点击直接跳转排课日历，减少流失。
*   **未预约提醒**: 核销但未预约的学员，在列表中高亮显示，并提供“一键提醒”按钮。

## 5. 响应式与适配
*   **Web端**: 采用栅格系统（Grid System），适配 1920px, 1440px, 1366px 常见分辨率。侧边栏在小屏下可折叠。
*   **移动端**: 遵循 iOS 和 Material Design 规范，触控区域高度不小于 44px。
