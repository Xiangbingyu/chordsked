核心需求：搭建一套适配音乐教培机构的综合管理系统，解决排课、核销、学员管理、教学辅助等核心痛点

1. 排课与匹配需求
 
- 按老师承载量（如部分老师最多带3人、部分可带5人）和学员进度等级（初级1-10课、中级10-20课等）设定匹配规则，老师水平需覆盖学员进度
- 支持多进度并行排课，避免同时间段不同进度学员冲突，同时满足学员固定时间和约课灵活性
- 团课不绑定老师，系统自动推荐适配时间；正式课（一对一/进阶）绑定老师，按固定安排排课
 
2. 团购核销与引流需求
 
- 打通抖音/美团等平台接口，实现下单后自动核销或通过短信链接、小程序引导核销，减少人工联系成本
- 自动同步平台未核销学员信息至系统，推送约课提醒，抓住冲动消费场景提升转化率
- 支持核销后不可随意退款（如24小时内可退、体验1课后满意不退）的规则设置
 
3. 学员信息管理需求
 
- 整合团课/正式课学员信息：基础信息（姓名、年龄、联系方式、家长信息）、课程相关（有无基础、乐器情况、想学曲目、课包类型、报名费用）、进度标签
- 替代现有手写记录和公共表格，实现信息数字化存储，老师上课前可快速调取学员进度、历史记录
 
4. 教学辅助需求
 
- 搭建教学知识库：含基本功练习库（文字+视频+节拍器/背景音乐，支持闯关制、练习时长记录）、曲谱库（按等级分类，可加密水印）、教学计划大纲，供老师快速调用
- 作业管理功能：支持学员上传短视频/音频/文字作业，老师审核标注，系统保留记录（可设近一周视频存储，长期保留文字记录）
- 进度追踪与反馈：系统统计同阶段学员进度对比，向学员/家长反馈进度快慢，通过类似Keep的趣味形式引导自主练习
 
5. 额外规划需求
 
- 短期：优先实现排课、核销、学员信息管理、基础教学辅助核心功能
- 长期：考虑搭建社区系统、在线商店，评估是否升级为APP（需结合资金投入）
- 可选功能：AI辅助课堂记录（一对一场景优先）、作业自动总结、新老师教学体系适配
