# 音乐教育培训 Web 应用：UI/UX 交互设计方案（教务端/教师端/学员端）

基于 [主要功能场景.md] 整理，覆盖一期核心流程，并为二期数据看板预留信息架构与交互扩展位。

## 1. 目标与范围

### 1.1 业务目标
- 提升团购核销到体验课预约与转化效率，减少漏跟进
- 用“排课/调课/取消/补课/扣课时”的可追溯流程降低教务沟通成本
- 用统一的课后反馈/作业/成长记录闭环提升学习体验与续费转化

### 1.2 端与角色
- 教务端（PC Web）：教务/校区负责人/管理员（RBAC + 校区数据权限）
- 教师端（PC Web + 移动端）：老师自管理可授课时间、课表、签到、课后反馈、作业批改
- 学员端（移动端为主）：学员/家长登录、约课、课包、提醒、作业、成长记录

## 2. 全局体验原则（跨三端）

### 2.1 核心设计原则
- 高频优先：课表/签到/约课入口始终可达，减少多层级跳转
- 强约束可视化：排课与约课的限制（老师时间/承载量/校区教室/授课类型/人群）用“可选范围 + 解释原因”的方式呈现
- 全链路留痕：调课/取消/补课/特殊扣减等关键节点记录“谁在何时做了什么”，可追溯
- 低学习成本：同类型操作统一组件与交互（表格/筛选/抽屉详情/批量操作/日历编辑）
- 及时提醒：预约未完成、作业未提交、课时不足、到期等采用“可配置规则 + 多渠道触达”

### 2.2 信息分层与反馈
- 列表页：默认展示最关键字段 + 状态标签 + 下一步行动（CTA）
- 详情页：分区块（基础信息/状态流/关联记录/操作日志）
- 操作反馈：表单内联校验 + 全局 Toast；影响流程的操作使用二次确认与结果回执

## 3. 核心对象与状态模型（用于统一交互语言）

### 3.1 关键对象
- 校区：校区信息、教室资源（排课约束）
- 课程模板：团购体验课/标准课/一对一课（授课类型、容量规则等）
- 课程实例（排课产物）：时间段、老师、教室、容量、已约人数/绑定学员
- 学员档案：基础信息 + 课包/课时 + 上课/作业/成长记录
- 课包：价格/库存/上下架 + 权益（课时、适用课程类型、有效期）
- 作业：类型（文/图/音/视）+ 截止时间 + 提交/批改记录
- 调课/取消申请：申请单 + 审核流 + 生效结果

### 3.2 状态建议（一期可用的最小集）

| 对象 | 状态 | 说明/触发 |
|---|---|---|
| 团购核销线索 | 已导入 → 已核销 → 已建档 → 已约体验 → 已签到 → 已转化 | 贯穿教务跟进与提醒 |
| 课程实例 | 可预约 → 已约满 → 已开课/可签到 → 已完成 → 已结算 | “结算”触发扣课时与记录生成 |
| 调课/取消申请 | 待审核 → 已同意/已拒绝 → 已生效 | 生效后同步课表与课时规则 |
| 作业 | 待发布 → 已发布 → 学员已提交/未提交 → 已批改 | 支持逾期状态与提醒 |

## 4. 导航与布局规范（建议）

### 4.1 PC Web（教务端/教师PC）
- 布局：左侧主导航 + 顶部条（校区切换/全局搜索/消息中心/个人菜单）
- 页面结构：筛选区（可折叠）+ 列表/日历主视图区 + 右侧抽屉详情/编辑（减少跳页）
- 常用交互：批量操作、保存筛选、导入导出、快捷新建（悬浮按钮或顶栏按钮）
  - 消息中心：顶栏铃铛+未读数，下拉预览最近消息；支持“查看全部”进入消息中心页

### 4.2 移动端（学员端/教师移动）
- 底部 Tab（建议 3–4 个）：高频优先，避免入口分散
- 详情页优先用分段信息卡 + 固定底部主按钮（提交/签到/约课）
- 上传多媒体：统一“选择来源（相册/拍摄/录音/文件）+ 进度 + 重试”

## 5. 教务端（PC Web）交互设计

### 5.1 信息架构（Sitemap）
- 工作台
  - 待办：核销未预约、待审核调课/取消、即将到期学员、异常/低活跃（一期可做占位）
  - 快捷入口：导入团购订单、创建学员、排课、发布公告
- 消息中心
  - 消息列表（未读/全部，筛选：待办提醒/审批结果/系统公告/触达结果）
  - 消息详情（内容、关联对象、跳转入口、时间线）
- 团购转化
  - 订单导入/列表
  - 核销登记/线索详情（建档/创建账号/引导预约）
- 排课与课表
  - 排课日历（周/月）
  - 课程模板管理
  - 教室资源管理（按校区）
- 调课/取消/补课
  - 申请列表（筛选：状态/校区/老师/学员/时间）
  - 申请详情（审批/改期方案/课时影响预估）
- 学员管理
  - 学员列表（含课时/到期/活跃标签）
  - 学员详情（抽屉为主，可打开全页：档案/课表/课时/作业/成长/购课信息）
- 教师管理
  - 教师列表/档案（授课类型/擅长/承载量）
- 课包管理
  - 课包列表（上下架/库存/价格）
- 公告/通知
  - 公告管理、消息模板/触达记录（一期可简化为公告 + 推送记录）
- 组织与权限
  - 校区管理
  - 账号/角色/权限树（RBAC）+ 数据权限（校区）
- 数据看板（二期）
  - 校区经营、教学质量、学员活跃与续费（预留）

### 5.2 关键页面与交互

#### A. 团购订单导入 → 核销登记 → 建档 → 引导预约（转化闭环）
1. 订单导入
   - 主操作：上传文件/粘贴数据（支持字段映射预览）
   - 校验：手机号缺失、重复订单号、校区缺失
   - 导入后：生成“待核销”列表，支持批量标记无效/重复
2. 核销登记（前台到店场景）
   - 快速检索：券码/手机号/姓名（优先手机号）
   - 核销表单：手机号必填；可选填预约登记表字段（姓名/年龄/意向科目等）
   - 动作：核销成功后自动进入“待建档/待创建账号”状态
3. 建档与创建账号
   - 交互：在右侧抽屉完成“学员档案最小集”（手机号、姓名、年龄段、校区、意向科目）
   - 自动：生成学员账号（用于学员端登录），并显示“一键复制登录指引”
4. 引导预约体验课
   - 明确下一步：展示“去学员端预约体验课”的二维码/链接，教务可直接在教务端代为选择推荐时段（可选）
5. 转化节点记录
   - 详情页时间轴：导入/核销/建档/预约/签到/转化
   - 提醒：核销后 X 天未预约，进入待办并触达（短信/站内/小程序订阅消息）

#### B. 排课管理（日历周/月）——“可排时间段搜索 + 约束解释”
1. 日历视图
   - 默认周视图；月视图用于概览与容量压力
   - 颜色编码：体验课/标准课/一对一；状态标签：可预约/已满/已开课/已完成
2. 新建排课（从空白时间格触发）
   - 第一步：选择校区与教室（教室作为硬约束）
   - 第二步：系统给出“可排老师与可排时间段”候选
     - 过滤条件：教师可授课时间、承载量、擅长科目、授课类型、成人/未成年/儿童等
     - 不可选项以禁用态展示，并在悬浮/侧栏说明原因（例如“该时段已达承载量”）
   - 第三步：选择课程模板（体验/标准/一对一）
     - 一对一：额外必选绑定学员（支持搜索/最近联系/待排清单）
3. 冲突处理
   - 冲突类型：老师时间冲突、教室冲突、容量冲突
   - 交互：弹窗展示冲突详情与可替代方案（推荐最近可用时段/同模板课程）
4. 编辑排课
   - 支持拖拽改时段（需再次校验约束）
   - 支持复制排课（用于固定课表）

#### C. 调课/取消处理（学员发起，教务/教师审核，留痕）
1. 申请列表（教务端）
   - 重点字段：学员/课程/原时间/申请类型（调课/取消）/原因/状态/影响课时提示
2. 审核详情
   - 上方：原课程信息卡
   - 中部：申请原因 + 证据附件（可选）
   - 下方：处理方案
     - 调课：推荐同类型课程列表（按时间优先）+ 手动搜索
     - 取消：显示“是否退课时/是否生成补课券”的规则预估（一期可先只提示，落账逻辑由后端确定）
3. 生效留痕
   - 自动写入：申请单时间轴 + 学员档案操作日志 + 课程实例变更记录

#### D. 学员/教师档案与课时视图（教务高频）
- 学员列表
  - 默认筛选：校区、课程类型、剩余课时区间、到期时间
  - 快捷标签：低活跃/即将到期/团购核销未预约
- 学员详情（抽屉为主，深度操作可打开全页）
  - 档案：预约登记表信息 + 学习目标/标签
  - 课表：最近 30 天 + 未来 30 天
  - 课时：课包余额、扣减明细（按课程记录）
  - 作业：按课程聚合
  - 成长记录：课后反馈时间线
  - 购课信息：课包订单（若一期暂未实现可占位）
  - 抽屉内快捷操作：编辑档案、发起调课/取消处理（教务视角）、发送提醒、复制登录指引
  - 打开全页场景：需要多区块纵向浏览、复杂编辑、跨模块跳转、复制链接分享/协同处理

### 5.3 权限与多校区
- 校区切换：顶栏全局控件；切换后列表/日历默认过滤对应校区数据
- 角色权限：权限树细分到页面 Tab 与操作项（新建/编辑/导入/审批/删除）
- 数据权限：按校区绑定（校区负责人可看本校区全量，教务看绑定校区）

## 6. 教师端交互设计（PC Web + 移动端）

### 6.1 信息架构（Sitemap，教师PC）
- 工作台
  - 今日课程
  - 待办：待签到、待写课后反馈、待批改作业、未提交提醒
  - 提醒：到期学员、核销未预约、作业未提交
- 消息中心
  - 消息列表（未读/全部，筛选：课程提醒/作业提醒/系统公告/审批结果）
  - 消息详情（内容、关联课程/学员、跳转入口）
- 我的课表
  - 日/周视图（筛选：校区、课程类型）
  - 课程详情（签到入口、课后反馈入口）
- 上课签到
  - 待签到列表（按今日/本周）
  - 签到详情（学员签到、请假标记、特殊扣减调整）
- 课后反馈
  - 待反馈队列
  - 反馈编辑（教学内容/课后回顾/逐学员评语/建议）
  - 发布作业（同页完成）
- 作业管理
  - 作业列表（筛选：课程/班级/截止时间/状态）
  - 批改页（文字/语音/视频点评）
  - 未提交提醒（批量）
- 学员管理
  - 已分配学员列表（课时情况、等级标注）
  - 学员详情（阶段测评报告、作业详情）
- 可授课时间与承载量
  - 可用时间配置（周重复 + 临时调整）
  - 授课偏好（授课类型、擅长科目、承载量）
- 全局看板
  - 统计：新增学员、核销数、上课节数、营收（若数据源未齐可占位）
  - 提醒聚合：到期、核销未预约、作业未提交

### 6.2 关键流程设计

#### A. 可授课时间维护（老师自助，减少教务沟通）
- 交互模型：周重复时间表（类似日历网格）+ 例外日期（请假/临时加课）
- 提交规则
  - 变更需立即生效（默认）或指定生效日期（可选）
  - 若变更导致已排课程冲突：阻止保存并列出冲突课程；提供“仅新增不减少”快速模式

#### B. 上课签到 → 自动生成上课记录 → 触发课时扣减（上课结束扣除）
- 入口：课表卡片上的“签到”按钮（仅在开课窗口可用）
- 签到页结构
  - 课程信息：时间、校区、教室、课程类型、人数
  - 学员列表：默认全选签到；支持逐个取消/标记请假
  - 特殊扣减：对某个学员选择扣减课时数（默认 1）
- 完成动作：结束签到后进入“已完成待反馈”状态；生成扣减明细

#### C. 课后反馈 → 同步成长记录 → 发布作业
- “待反馈”队列：按课程排序，支持一键进入
- 录入体验
  - 顶部：公共内容（教学内容、回顾、课程总结）
  - 下方：学员逐卡片填写（表现、评语、下节建议）
  - 末尾：作业发布（可选作业模板，选择类型与截止时间）
- 防丢：输入自动保存草稿，离开提示

#### D. 作业批改（多媒体为主）
- 作业详情
  - 学员提交内容：图/音/视播放组件统一
  - 点评：文字 + 语音/视频点评（二期可扩展）
  - 状态：已批改/待批改/逾期未交
- 批量能力
  - 对“未提交”一键提醒
  - 对“已提交”快速下一个（键盘导航/移动端手势）

### 6.3 教师移动端（建议 Tab）
- 课表：今日/本周，快捷签到
- 作业：待批改/待提醒
- 我的：可授课时间、个人信息、消息

## 7. 学员端交互设计（移动端为主）

### 7.1 信息架构（建议 Tab）
- 课表
  - 今日课程卡片、未来日历
  - 课程详情（地点/老师/注意事项/签到规则提示）
- 学习
  - 约课（体验课/正式课/团课）
  - 作业（待完成、已提交、已批改）
  - 成长（课后反馈时间线、阶段测评报告；一期可先展示反馈）
- 我的
  - 剩余课时、课包、个人信息、通知设置
  - 我的申请（调课/取消进度）

### 7.2 关键流程设计

#### A. 登录（手机号/微信）
- 首次登录：手机号验证 → 绑定账号 → 引导完善基础信息（可跳过）
- 已建档未登录：教务端创建后，学员端展示“新学员引导”（包含校区、体验课预约入口）

#### B. 查看课表与剩余课时（高频）
- 课表首页优先展示
  - 今日课程（时间、校区、教室、老师）
  - 剩余课时（醒目数值 + “去购课/联系教务”）
- 状态解释
  - 未到时间：显示提醒设置
  - 可调课：显示“申请调课/取消”（遵循“学员不可自己调课”的约束：学员只能发起申请，不能直接改课）

#### C. 预约体验/团课/正式课
1. 选择课程类型
   - 体验课：默认推荐校区与时间段（基于教务排课产物）
   - 团课：强调“系统推荐时间”，但允许查看其他可选时间
   - 正式课：允许选老师（按擅长科目/可约时段展示）
2. 选择时间
   - 交互：时间列表 + 日历切换
   - 不可选原因提示：已满/不符合人群/已过截止预约时间
3. 确认预约
   - 信息确认：时间、地点、老师、注意事项
   - 成功后：写入课表，并触发课前提醒订阅

#### D. 调课/取消申请（提交申请 + 状态跟踪）
- 发起入口：课程详情页
- 表单字段：申请类型（调课/取消）、原因（必填）、期望时间（调课可选）、附件（可选）
- 提交后：进入“我的 > 我的申请”列表，可查看审批进度与结果

#### E. 作业提交（多媒体）
- 作业详情页
  - 截止时间倒计时（逾期显示明确提示）
  - 提交区：文字输入 + 多媒体附件（图/音/视）
  - 上传与保存：支持草稿；弱网重试
- 提交后：状态变为“已提交待批改”，并允许追加说明（可配置是否允许）

#### F. 查看课后反馈/成长记录
- 学习 > 成长：按课程时间线展示反馈摘要
- 详情：老师评语、建议、作业链接、阶段测评（若有）

### 7.3 提醒策略（学员端）
- 课前提醒：提前 1 天 + 6 小时
- 团购核销未预约提醒：核销后按规则触达（例如第 1/3/7 天）
- 作业未提交提醒：截止前 24 小时、截止后 2 小时
- 剩余课时提醒：低于阈值（如 ≤2）与到期前 N 天

## 8. 二期数据看板（信息架构预留）

### 8.1 校区负责人监管（教务端）
- 教学质量：教师作业点评覆盖率、档案完整度
- 异常学员：低活跃/到期清单
- 运营数据：实时上课数据、约课情况、续费情况

### 8.2 教师个人数据（教师端）
- 课时数、上课时长、出勤率、完课率、满意度（评分）

## 9. 组件与模式清单（便于前端落地）

### 9.1 复用组件（PC）
- 日历排课组件：周/月视图、拖拽、冲突提示、容量显示
- 筛选器：多条件 + 保存筛选 + 快速清空
- 详情抽屉：对象信息卡 + 操作区 + 时间轴（日志）
- 多媒体预览：图片/音频/视频统一容器
- 批量操作条：选择后浮现（批量提醒/批量变更状态）

### 9.2 复用组件（移动）
- 课程卡片：时间、地点、老师、状态、主按钮
- 上传组件：选择来源 + 进度 + 重试 + 预览
- 时间段选择器：列表 + 日历切换 + 不可选原因

## 10. 可用性与可访问性（最低要求）
- 可访问性：键盘可达（PC 端表格/抽屉/弹窗）、清晰焦点态、颜色对比达标
- 空态：每个列表/日历空态提供“下一步建议”（如“去导入订单/去排课”）
- 错误与异常：网络失败可重试；导入失败提供可下载错误明细
- 响应式：教务端与教师PC在 1280px 以上为主；低于阈值时切换为紧凑布局（折叠筛选、表格列收起）
