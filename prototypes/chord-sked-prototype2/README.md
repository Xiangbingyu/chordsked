# ChordSked vprototypes2

用于客户演示的一期静态原型，基于 `doc/UIUX交互设计方案.md` 与 `doc/主要功能场景.md` 制作。

## 运行方式

1. 进入目录：`vprototypes2`
2. 安装依赖：
   ```bash
   npm install
   ```
3. 启动本地演示：
   ```bash
   npm run dev
   ```
4. 浏览器打开终端输出地址（默认 `http://localhost:5173`）

## 演示内容

- 教务端：工作台、团购转化、排课课表、调课取消、学员管理、教师管理、课包管理、公告通知、组织权限
- 教师端：工作台、我的课表、上课签到、课后反馈、作业管理、可授课时间
- 学员端：课表、约课、作业、成长、我的
- 数据来源：全部为前端本地 Mock 数据，无服务端依赖
